# Calculator Web App

## Description
The Calculator Web App is a simple yet functional calculator built using HTML, CSS, and JavaScript. It allows users to perform basic arithmetic operations such as addition, subtraction, multiplication, and division in a user-friendly interface.

## Key Features
- **Basic Arithmetic Functions**: Perform addition, subtraction, multiplication, and division.
- **User-Friendly Interface**: Intuitive layout that’s easy to navigate.
- **Responsive Design**: Adjusts dimensions based on the browser window.
- **History Tracking**: Keeps track of previous operations until cleared.
- **Clear Functionality**: Easily reset or clear calculations.
## Installation Instructions\nTo run the Calculator Web App locally on your machine, follow these steps:

1. **Clone the Repository**:
   ```bash
      git clone https://github.com/yourusername/calculator-web-app.git
         ```
         
2. **Navigate to the Project Directory**:
   ```bash
      cd calculator-web-app
         ```
         
3. **Open the HTML File**:
   Open `index.html` in your web browser of choice.
   
   ## Usage Examples
   1. Open the calculator in a web browser.
   2. Click the number buttons to enter your numbers.
   3. Select an operator (+, -, *, ÷) to perform the operation.
   4. After entering the second number, click `=` to see the result.
   5. Use `clear` to reset the calculator.
   
   *Example Calculation*:
   - Input: 5, then +, then 3, then =.
   - Output: 8
   
   ## File/Project Overview
   Here’s a brief overview of the main files in the project:
   
   - `index.html`: The HTML structure of the calculator, including the display window and buttons.
   - `script.js`: The JavaScript code that contains the logic for arithmetic operations and handling user interactions.
   - `styles.css`: The CSS for styling the calculator layout, buttons, and overall appearance.
   
By following the instructions above, you can set up and run the Calculator Web App in your local environment. Enjoy calculating!
